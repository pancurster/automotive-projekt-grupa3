# automotive-projekt-grupa3

Group project for automotive data

## Configuration

1) `$ python -m venv .venv`
2) `$ source .venv/bin/activate`
3) `$ pip install -e .`

4) For tests/dev dependencies: `$ pip install -e ".[dev]"`

## Checks

- Run tests: `$ pytest`
- Run Pylint: `$ pylint src/automotive tests`
